# AI Product Describer

A local command-line tool that trains a small decoder-only GPT from random initialization on product-description examples, then samples new descriptions from product details. It uses PyTorch; it does **not** call a hosted language-model API.

## What it does

- Collects a small example corpus for reusable fabric bags and organisers.
- Learns a byte-level Byte-Pair Encoding (BPE) tokenizer from that corpus.
- Uses learned token and position embeddings.
- Implements masked causal self-attention and transformer decoder blocks.
- Trains a GPT language model with next-token prediction.
- Generates text autoregressively and exposes it through a CLI.

## Requirements

Python 3.12 or 3.13 and pip. Training runs on CPU; a CUDA-enabled PyTorch installation can be used on a compatible GPU. Dependencies are pinned in `requirements.txt`.

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Run it

```bash
python -m app.cli hello
python -m app.cli prepare
python -m app.cli train --epochs 400
python -m app.cli generate --prompt "Product: cotton tote. Features: roomy, reinforced handles. Description:"
python -m app.cli describe --name "Meadow Tote" --features "cotton canvas, botanical print, inner pocket" --tone cheerful --length medium --output outputs/meadow-tote.txt
pytest -q
```

The first training run creates `data/product_descriptions.txt`, `models/tokenizer.json`, `models/product_gpt.pt`, and `outputs/training_metrics.json`. Add more examples (separated by blank lines) to the corpus and run training again to retrain from scratch.

## Milestones

- [x] **1. Data collection:** a reproducible starter corpus is created at `data/product_descriptions.txt`.
- [x] **2. BPE and embeddings:** byte-level BPE merges are learned and saved; token and positional embeddings are part of the model.
- [x] **3. Causal attention and transformer:** masked multi-head self-attention, feed-forward layers, residual connections and layer normalization.
- [x] **4. GPT training:** next-token training loop, gradient clipping, seeded initialization and saved checkpoint/metrics.
- [x] **5. Text generation:** autoregressive sampling with temperature and top-k filtering.
- [x] **6. CLI:** `prepare`, `train`, `generate`, and `describe` commands.

## Evaluation and limitations

The training command records periodic training loss in `outputs/training_metrics.json`. A sample CLI output and experiment notes are included in `outputs/sample_generation.txt` and `outputs/evaluation.md`. In the recorded 400-step run, training loss fell from 5.89045 to 0.32493. This is a demonstration-scale language model, not a commercial copywriter: the corpus is small and narrow, generated text can be repetitive or inaccurate, and loss on this tiny training corpus is not evidence of general language quality. The sample output documents that limitation rather than claiming production quality. Always verify product claims before publishing. A meaningful next evaluation requires a larger permissioned corpus, a held-out set, and human ratings of factuality, readability and relevance against a simple nearest-example baseline.

The initial corpus consists of original example descriptions written for this project (not scraped product listings). To improve results, add a larger, permissioned set of real descriptions in the same format and retrain.

## Tests

Run `pytest -q`. The suite contains eight tests covering the six milestones and CLI smoke checks; GitHub Actions runs the same suite on pushes and pull requests.

## Project layout

```text
app/core.py       BPE, embeddings, attention, GPT, training and sampling

data/             local training corpus (created on first prepare/train)
models/           tokenizer and trained model checkpoint
outputs/          training metrics and generated descriptions
tests/            milestone and smoke tests
```

## Security

No API key is needed. Do not commit `.env`, private datasets, or customer information. Local training artifacts are generated by the commands above.
